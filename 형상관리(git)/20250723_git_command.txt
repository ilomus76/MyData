#### 이곳은 git 관련 정보를 기록해 두는 곳입니다. 

CLI [command line interface]
git log : 로그 확인 -> 매일 계정과 시간 , 업데이트 내용등을 볼수 있다. 


git branch : 파일을 복사해서 업데이트 하는 포인트 
로컬 폴더나 원격 폴더에서 처음의 git 관리 단계는 master or main 이된다. 
git branch 로 branch를 하나 만들면 그것은 똑같은 파일을 복제하여 파일을 없데이트 하는 구간이 된다. 
git 은 처음에 main 단계를 시작으로해서 git branch 를 통해 업데이트 단계를 만드는데 항상 유저 / 고객은 main을 바라보고 있다.



#### 로컬 repogitory ########

working directory 

1) git init  : git 이 초기화 되어 git working directory로 시작이 되는 단계



2) git restore 
  # git restore . /git restore --worktree . : 현재 폴더 아래 수정한 모든 파일을 취소





3) stage : git 상태에서 추적을 받기 시작하는 상태. -> git add "file name" 으로 부터 시작된다.


git add . / git add 'file name'

3-1) git add 되어 트래킹 되는 파일들을 그 이전으로 돌리기 위해서 하는 명령 
git restore staged 'file name



3) commit : 확인 완료 

git commit -m "comment"

3-1) git commit 되어 완료되었을때 stage / 혹은 그 이전으로 되돌리는 명령
git reset -soft Head~1
git reset -mixed Head~1
git reset -hard Head~1
